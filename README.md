# 🎮 Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

[Play Tic Tac Toe](https://codewithvijay01.github.io/tic-tac-toe-game/)

## ✨ Features

- 🎮 Interactive two-player gameplay
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔄 Game reset functionality
- 🔊 Click sound effects
- 🎵 Victory sound
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Audio

## 🎯 How to Play

1. Open the game using the Live Demo link.
2. Player 1 plays as `X`.
3. Player 2 plays as `O`.
4. Take turns placing your symbol.
5. The first player to get three symbols in a row wins.
6. If all cells are filled without a winner, the game is a draw.
